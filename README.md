# ATLAS JAPAN — 日本市町村クイズ

市役所・町役場・村役場の登録地点を日本地図上で探し、回答との距離で得点が決まる静的サイトです。

- 市792、町村926の計1,718自治体。「初級」「中級」「上級」から選択
- 15問（初期選択）／30問。1回の出題に重複なし、時間制限なし
- 都道府県・市町村名・読みがなを表示。東京都特別区・政令指定都市の行政区は対象外
- クリック／タップでピンを設置し、別ボタンで回答を確定
- 拡大縮小、ドラッグ、ピンチ、キーボードでのピン操作に対応
- 誤差距離・役所の位置・問題別の振り返り、結果共有とコピー
- 共有URLは設定・合計点のみを保存する自己申告値。問題順や位置履歴は含まない
- 地図・役所データ・ライブラリは同梱。APIキー、外部地図タイル、ビルド、サーバー処理は不要

## 難易度

初級は主要都市・有名な観光地、中級は地方都市や観光地の町村、上級はそれ以外の市町村です。知名度と位置の推測しやすさを考慮した本クイズ独自の分類で、客観的な知名度調査・人口順位に基づくものではありません。

初級にも箱根町・軽井沢町・白川村を含め、上級にも市を含めています。行政区分による分割ではありません。都道府県名・読みがなのヒントと距離採点は全難易度で共通です。分類リストは `quiz.js` に定義しています。

## 採点方式を選んだ理由

完全一致方式は自治体の領域を覚えるゲームに向いており、採点が明快です。一方、小さな自治体と大きな自治体で選択の難しさが異なり、僅かに隣を選んでも0点になります。距離方式は近くまで分かった回答にも点が入り、全国の町村に挑戦する入り口になります。本版は距離方式を採用し、「市町村内なら正解」ではなく「役所の登録地点を探す」ルールを明示しています。

1問1,000点。地球上の2点間の最短距離をHaversine式（平均地球半径6,371.0088km）で計算します。

`round(1000 × exp(-max(0, distanceKm - 5) / 100))`

| 誤差 | 得点 |
| --- | ---: |
| 0〜5km | 1,000 |
| 10km | 951 |
| 50km | 638 |
| 100km | 387 |
| 200km | 142 |
| 500km | 7 |

未回答は0点。15問は15,000点、30問は30,000点満点です。異なる問題数の比較用に得点率も表示。平均誤差は回答した問題のみを対象とし、未回答は振り返りに明記します。

5kmの満点範囲は、簡略化された地図とスマートフォンでの操作を考慮した初期設定です。1m単位で庁舎を探す用途ではありません。役場データは取得日のスナップショットで、すべての庁舎移転に追従することは保証しません。データ出典・制限はゲーム内と [assets/SOURCES.md](assets/SOURCES.md) に記載しています。

## ローカル確認

Node.jsで `node check.cjs` を実行すると、出題の重複・対象自治体・地図の投影範囲・距離計算・得点の単調性・共有URLと共有文・ローカル参照を検証します。

`node server.cjs` を実行し、http://127.0.0.1:4174/japan-map-quiz/ を開きます。既存の世界地図版（ポート4173）とは別に起動できます。ファイルを直接開く代わりにHTTP経由で確認してください。

3. Branchを `main`、フォルダーを `/ (root)` にしてSave
4. Pagesのデプロイ完了後、表示された公開URLを開く

リポジトリ名を `japan-map-quiz` とした場合のURL例は `https://<アカウント名>.github.io/japan-map-quiz/` です。HTML・CSS・JavaScript・データは相対パスなのでプロジェクト配下のURLでも動作します。`.nojekyll` を含めてください。新しいデータや修正をpushすると再配信されます。
