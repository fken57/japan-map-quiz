# ATLAS JAPAN — 日本市町村クイズ

日本地図の市町村の区域をクリック・タップして回答する静的サイトです。正しい自治体を選べば1問正解です。

- 市792、町村926の計1,718自治体。「初級」「中級」「上級」から選択
- 15問（初期選択）／30問。1回の出題に重複なし、時間制限なし
- 都道府県・市町村名・読みがなを表示。東京都特別区・政令指定都市の行政区は対象外
- クリック／タップで市町村の区域を選択し、別ボタンで回答を確定
- 1,718市町村の境界を表示。政令指定都市の行政区を統合し、市全体を選択
- 拡大縮小、ドラッグ、ピンチ、キーボードでの区域選択に対応。「県」ボタンで出題県を表示
- 選択は黄色、正解は緑、不正解は赤。回答前は市町村名を表示しない
- 正解数・正答率・未回答数、問題別の振り返り、結果共有とコピー
- 共有URLは設定・正解数のみを保存する自己申告値。問題順や回答履歴は含まない
- 地図・自治体名・ライブラリは同梱。APIキー、外部地図タイル、ビルド、サーバー処理は不要

## 難易度

初級は主要都市・有名な観光地、中級は地方都市や観光地の町村、上級はそれ以外の市町村です。知名度と位置の推測しやすさを考慮した本クイズ独自の分類で、客観的な知名度調査・人口順位に基づくものではありません。

初級にも箱根町・軽井沢町・白川村を含め、上級にも市を含めています。行政区分による分割ではありません。都道府県名・読みがなのヒントと完全一致の採点は全難易度で共通です。分類リストは `quiz.js` に定義しています。

## 採点と地図

回答と問題の地方公共団体コードが完全一致したときに1問正解です。同名でも別の県の自治体は不正解です。未回答と不正解は正解数に加算しません。飛び地・離島も同じ自治体の区域として選択できます。

旧距離採点版の共有スコアと混同しないよう、新リンクは `#result=area.easy.15.10` 形式です。旧形式は表示しません。

市町村境界は国土数値情報「行政区域データ」2025年版を共同通信がTopoJSON化したデータを再加工しています。小島や細い境界の一部は簡略化されています。詳細と利用条件は [assets/SOURCES.md](assets/SOURCES.md) を参照してください。

## ローカル確認

Node.jsで `node check.cjs` を実行すると、全自治体と境界の対応・離島・政令市の統合・難易度別の出題・完全一致の判定・共有URLと共有文・ローカル参照を検証します。

`node server.cjs` を実行し、http://127.0.0.1:4174/japan-map-quiz/ を開きます。既存の世界地図版（ポート4173）とは別に起動できます。ファイルを直接開く代わりにHTTP経由で確認してください。

1. GitHubに新しいリポジトリを作成し、このフォルダーの内容を `main` にpush
2. Settings → Pages → Build and deployment → Deploy from a branch
3. Branchを `main`、フォルダーを `/ (root)` にしてSave
4. Pagesのデプロイ完了後、表示された公開URLを開く

リポジトリ名を `japan-map-quiz` とした場合のURL例は `https://<アカウント名>.github.io/japan-map-quiz/` です。HTML・CSS・JavaScript・データは相対パスなのでプロジェクト配下のURLでも動作します。`.nojekyll` を含めてください。新しいデータや修正をpushすると再配信されます。

公開後の更新は、このフォルダーで変更をコミットして `main` にpushします。GitHub Pagesが自動的に再配信します。
